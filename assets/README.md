# Asset richiesti

Inserisci qui i file con questi esatti nomi:

| File                  | Sezione                        | Note                          |
|-----------------------|--------------------------------|-------------------------------|
| `icona.png`           | Navbar (sinistra)              | PNG con sfondo trasparente    |
| `logo.png`            | Hero (centro) + Footer         | PNG con sfondo trasparente    |
| `video.mp4`           | Sezione video (sotto hero)     | MP4, max ~30 secondi          |
| `hero.jpg`            | Hero fullscreen                | 1920×1080 px minimo           |
| `about.jpg`           | Sezione intro        | 900×700 px            |
| `filosofia.jpg`       | Sezione non-AYCE     | 900×700 px            |
| `menu-nigiri.jpg`     | Menu – Nigiri        | 600×520 px            |
| `menu-maki.jpg`       | Menu – Maki          | 600×520 px            |
| `menu-poke.jpg`       | Menu – Poké          | 600×520 px            |
| `menu-speciali.jpg`   | Menu – Speciali      | 600×520 px            |
| `sede-sanpietro.jpg`  | Sede San Pietro      | 700×440 px            |
| `sede-vignola.jpg`    | Sede Vignola         | 700×440 px            |
| `sede-villafranca.jpg`| Sede Villafranca     | 700×440 px            |
| `hours.jpg`           | Sezione orari        | 900×700 px            |

Tutti i formati JPG o WEBP sono accettati. Se mancano, le sezioni mostrano sfondi colorati al posto delle immagini.
